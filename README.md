# Emberfall

Single-file HTML5 pixel action RPG (`index.html`).

- **Solo play:** open `index.html` in any browser. Progress saves in the browser.
- **Online play (current):** published as a shared Claude artifact. Players see each other, chat, party up, add friends and found guilds.
- **Supabase (planned):** `supabase/schema.sql` holds the database setup for running the social layer on Supabase project `msbumodfvmqllmpcfryk`. It has not been applied yet; paste it into the Supabase SQL Editor to set it up.
